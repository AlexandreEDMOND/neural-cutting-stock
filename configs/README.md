# Configurations

Ce dossier accueillera les configurations versionnées des solveurs, générateurs d’instances et campagnes de benchmark.

Une configuration publiée devra préciser au minimum les graines, tolérances numériques, limites de temps, politique de threads, versions du générateur et du solveur, ainsi que la définition de la catégorie de difficulté. Aucun seuil `SMALL`/`MEDIUM`/`LARGE`/`XL` n’est fixé avant le profilage classique de la Phase 2.

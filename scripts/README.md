# Scripts

Les scripts seront des points d’entrée fins vers le paquet `neural_cutting_stock`. La logique de résolution, de benchmark et de visualisation restera dans `src/` afin d’être testable.

Les premiers scripts attendus sont l’exécution de la baseline classique, la génération d’instances reproductibles, la campagne de benchmark et la création des graphiques à partir des résultats persistés.
